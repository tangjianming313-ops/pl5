# 斌斌排码 · 前四位工作台

移动端友好的排列五前四位筛选网站。只分析万、千、百、十，完整五位输入自动忽略个位；所有号码以字符串保存，保留前导零。

## 功能

- 0000–9999 全量重算；固定位置排码、历史窗口、全历史次数、和值、重复结构、012 路、近期定位、合分①④、单双与大小形态。
- 默认常用预设：最近1500期完整号码排除、万4千4百8十1、和值9–30、仅普通单对子与无对子、012至少两路、近2期同位≥2及近10期同位≥3排除、合分①④。预设可修改，不代表之后用户确认的最新规则。
- 导入 TXT/CSV/TSV，识别序号与号码；支持完整五位。可反转导入顺序。异常行阻止导入；开奖重复不去重。
- 预置用户提供的7,763期前四位历史（2026-10-29提供，截至4157）。历史序号不是官方期号。
- 单期追加、移除末期、历史导出、JSON完整备份与恢复。
- 全部、无对子、普通单对子、缩水池视图；前缀搜索、万位筛选；按万位升序复制、分批复制、TXT/CSV导出。
- 缩水池：主池内普通单对子、和值9–25、万位2/3/5/7/9。
- 10/20/30/50/60/100/200期滚动回测：每个目标仅使用此前历史；不使用未来数据；显示命中率、平均候选数、最长未中与逐期明细。
- 本地方案保存、同源多标签页同步。数据保存在浏览器localStorage，跨设备通过备份转移。

## 运行

零外部依赖、无需构建。用任意静态HTTP服务器服务`dist/`目录。不要直接以file://打开，以免模块和历史读取被浏览器拦截。

```sh
python3 -m http.server 8080 --directory dist
```

访问 http://localhost:8080 。测试需要Node.js 20及以上：

```sh
npm test
```

## 文件

- `dist/engine.mjs`：独立的号码生成、格式校验、规则说明和无未来数据回测模块。
- `dist/app.mjs`：交互、持久化、导入导出。
- `dist/index.html`、`dist/styles.css`：响应式界面，无外部字体或CDN依赖。
- `dist/history.json`：初始历史，最新在末尾，重复期保留。
- `tests/engine.test.mjs`：边界、独立实现全量核对、格式和滚动窗口回归测试。

## 口径与限制

历史排除先按期截取，再去重；同位排除逐期比较，不能跨期相加。合分①：候选(千+百+十)%10等于上期(万+百)%10则排除。合分④：候选(千+百)%10等于上期(百+十)%10则排除。

回测参数固定为当前设置，只让历史及依赖历史的参照滚动；若参数是观察本段历史后挑选的，仍可能存在参数选择偏差。命中率只描述历史，候选规模变化会影响覆盖率。

网站没有自动抓取开奖、账户系统、付费或金币功能；需要手动追加或导入开奖。浏览器本地保存不是云端同步，清除站点数据会移除本地修改。CSV号码列应按文本导入表格软件，TXT与JSON可保留前导零。

本工具用于按规则筛选和统计，不预测开奖结果，不保证中奖。
