# 斌斌数据研究院 · 微信原生小程序（开发版）

这是独立于根目录 GitHub Pages 网站的微信原生小程序源码，位于 `miniprogram/`。已有开奖历史 7763 期（前四位）随包内置，排码计算已移植，支持原码/无对子/普通单对子和四批复制、历史查看、手动补录、开奖数据同步状态。

## 本地预览
1. 在电脑安装微信开发者工具并登录。
2. 导入本仓库的 `miniprogram` 文件夹（不是仓库根目录）。
3. `project.config.json` 中的 `touristappid` 仅用于本地体验；要真机预览、分享、发布，替换为自己微信小程序的真实 AppID。
4. 在微信公众平台为 `https://tangjianming313-ops.github.io` 配置合法的 request 域名（需要符合微信平台规则及资质要求）。开发阶段可以在工具中临时关闭域名校验，仅用于调试。
5. 通过开发者工具预览、测试，再按微信审核流程提交发布。

## 数据更新说明
小程序调用 `https://tangjianming313-ops.github.io/pl5/draws-auto.json`；这不是实时开奖接口，而是网站 GitHub Actions 成功验证并提交后的数据快照。没有新数据时会显示等待更新，不伪称今日开奖。内置历史最后一期前四位为 `4157`，自动同步可能晚于实际开奖。用户手动补录仅保存在当前设备，不会上传 GitHub。

## 合规
仅提供历史数据和统计分析，不销售彩票、不代购、不提供充值或下注。上线审核由微信平台决定；请勿宣称保本、必中或实时直播。
