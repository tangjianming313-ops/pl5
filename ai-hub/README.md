# AI HUB｜一站式 AI 官方订阅中心

## 当前阶段：MVP v0.2

这是独立开发分支中的静态原型，尚未部署为正式商城。

### 已实现
- 响应式商城首页、品牌目录、搜索和分类
- 跳转品牌官方购买/服务页面，不代收款
- 个人订阅记录：本机添加、删除、到期日期展示、JSON 导出
- PWA manifest、离线缓存基础
- 管理后台规划页（**非可登录后台**）
- Supabase SQL 初始模型及订阅记录的用户级 RLS

### 尚未实现
- 真正的用户账户、跨设备同步
- 可登录的管理员后台、商品编辑
- 站内订单、支付、发货与售后
- 安卓 APK、独立域名与正式部署

### 目录
- `index.html` 商城首页
- `account.html` 本机订阅记录
- `admin.html` 后台规划
- `schema.sql` 未来数据库模型
- `manifest.webmanifest` PWA 配置
- `sw.js` 基础缓存

### 合规约束
不得冒充品牌官方代理；没有授权不得转售第三方订阅；不得索取第三方账号密码。商品价格、地区和购买资格应以服务商官方实时页面为准。

### 下一步
1. 创建 AI HUB 独立仓库（不要将此项目合并到原 P5 网站）。
2. 配置独立静态部署和域名。
3. 建立 Supabase 项目，应用数据库模型并审核 RLS。
4. 接入真实登录及管理员权限，建立授权商品的上架审核。
5. 获得经销授权后，再实现支付订单和交付；之后封装安卓应用。
